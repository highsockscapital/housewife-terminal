# Core GNU userland set for glibc-bootstrap-arm64.tar.xz (Phase 3).
#
# One package name per line; blank lines and lines starting with '#' are
# ignored. Exact pins allowed as "name=version".
#
# These are resolved transitively (Depends + Pre-Depends only, no Recommends)
# against the Debian archive index by scripts/fetch-debian-packages.sh, then
# extracted, relocated under $PREFIX/glibc, and ELF-patched at build time by
# scripts/patch-elf.sh. Nothing runs patchelf on-device.
#
# libc6 (+libcrypt1/libgcc-s1 via deps) ships the proven stock Debian
# ld-linux/libc: a from-source cross build segfaulted instantly on-device.
# apt/dpkg seed the on-device package manager (configs + dummy admin utils
# are generated at pack time; maintainer scripts run on-device, never here).
